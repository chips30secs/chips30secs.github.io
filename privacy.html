Privacy Policy

chips-shorts (CHIPS IN 30s) · Last updated 2 November 2026

What this app is

chips-shorts is a private publishing tool used only by the owner of the YouTube channel chips_30sec to upload that channel's own videos. It is not offered to the public and no one else signs in to it.

What data it accesses

With the channel owner's permission, the app uses the YouTube Data API with the youtube.upload permission to upload videos, titles, descriptions and tags to the owner's own channel. It does not read viewer data, comments, subscribers, emails, contacts or any other personal information.

How data is stored

The only credential kept is the owner's sign-in token, stored as an encrypted secret in the owner's private GitHub repository. Video files are deleted from that repository after upload. No data is sold, shared, or used for advertising.

Google API Services

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. YouTube use is also subject to the YouTube Terms of Service and the Google Privacy Policy.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions.
